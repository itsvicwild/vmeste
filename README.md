# «Вместе» — интерактивная презентация

Платформа поддержки молодых семей на этапе адаптации: знания, договорённости, специалисты и сообщество.

🔗 **Открыть презентацию:** `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

## Управление

Листайте слайды кнопками на экране или с клавиатуры (стрелки). Презентация работает на телефоне и компьютере.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `index.html` | сама презентация (один файл, всё внутри) |
| `404.html` | страница на случай неверной ссылки |
| `favicon.svg` | иконка во вкладке браузера |
| `.nojekyll` | отключает обработку Jekyll, сайт отдаётся как есть |
| `robots.txt` | разрешает индексацию поисковиками |
| `.github/workflows/pages.yml` | автодеплой при каждом изменении (необязательно) |

## Как опубликовать

1. Создайте репозиторий на GitHub (Public).
2. Загрузите все файлы **вместе с папкой `.github`**.
3. `Settings` → `Pages` → `Source`: **GitHub Actions** (или `Deploy from a branch` → `main` / `root`, тогда `pages.yml` не нужен).
4. Через 1–2 минуты сайт откроется по ссылке выше.

## Как обновить

Замените `index.html` новой версией и сделайте commit. Сайт обновится сам.
